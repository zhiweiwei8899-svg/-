# -

软件开发专用仓库。

## 目录结构

```
.
├── src/       # 源代码
├── scripts/   # 构建、部署等辅助脚本
├── tests/     # 测试
└── docs/      # 设计与使用文档
```

## 开始

约定后续补充：技术栈选型、依赖管理方式、本地运行命令。

## 提交规范

采用 Conventional Commits：

```
feat: 新功能
fix:    缺陷修复
docs:   仅文档变更
refactor: 重构（不改变外部行为）
chore:  构建/杂项维护
```

单次提交只做一件事，标题控制在 50 字以内，必要时在正文说明动机与影响范围。

## 分支约定

- `main`：始终可用，受保护，仅通过 PR 合入
- `feat/<简述>`、`fix/<简述>`：功能与修复分支，合入后删除
